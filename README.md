# Evil Permit

Ứng dụng Android bảo vệ quyền riêng tư: tự thu hồi quyền mà app khác không cần, chặn đọc clipboard, quét Wi-Fi, thống kê sử dụng và các thông tin chuyên sâu khác qua AppOps, có hoàn tác một chạm.

Không cần root. Dùng [Shizuku](https://github.com/RikkaApps/Shizuku) để chạy lệnh với quyền shell.

> Đang phát triển. Chưa có bản phát hành.

## Build

```bash
./gradlew assembleDebug
```

Yêu cầu JDK 17 và Android SDK 35. APK debug của mỗi lần build có trong tab Actions của repo.
